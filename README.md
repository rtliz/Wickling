# Wickling · ภูติตะเกียง

เกมปริศนามือถือ: ดวงไฟตัวน้อยเดินได้รอบละ 10 วินาที แล้วทุกรอบจะกลายเป็นเงาควันที่เดินซ้ำแบบเดิม ใช้ "ตัวเองเมื่อกี้" หลายตัวช่วยกันกดสวิตช์ บังเลเซอร์ และพาดวงไฟไปถึงทางออก

- 13 ห้อง (ห้องพื้นฐาน + ห้องสอนสกิล) · หอคอย ∞ ห้องสุ่มไม่รู้จบ
- ต้นไม้สกิล 11 สกิล ปลดล็อกด้วยดาว ติดตัว 2 ช่อง พร้อมวิดีโอตัวอย่าง

```bash
pnpm install
pnpm dev      # เปิด http://localhost:5173
pnpm check    # ตรวจ: typecheck + ให้โปรแกรมเล่นผ่านทุกห้องและหอคอย 200 ชั้น
pnpm build
```
