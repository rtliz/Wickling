ชื่อไทย **ภูติตะเกียง** · ชื่ออังกฤษยังไม่ล็อก ("Echo Wisp" มีเกมบน Steam ใช้แล้ว ห้ามใช้) · ชื่อทำงานเดิม "ตัวฉันเมื่อกี้ / Echo Me"

ต้นแบบใช้แล้วทิ้ง (ตามสกิล `prototype` ของสตูดิโอ) · ผล: **PROCEED** (2026-11-02) เกมจริงอยู่ที่ราก repo นี้ (`src/`) · ไฟล์ในโฟลเดอร์นี้เก็บไว้อ้างอิง ห้าม import เข้าโค้ดจริง · ใบสรุปเกมย้ายไป `../../GAME_BRIEF.md`

## ตัดสินใจไปแล้ว

- เวลาเดินความเร็วปกติเสมอ (ไม่เร่งเวลาตอนยืนนิ่ง) · ไม่มีเพลงจากเงา · ไม่มีตัวเลขวินาทีบนเส้นทาง
- แนวภาพ: ภูติตะเกียง (ดวงไฟในวิหารมืด เงาเป็นควันเรืองแสง)
- ระบบสกิล: ต้นไม้สกิล สกิลคือท่าใหม่ ไม่ใช่ค่าพลัง · ทุกสกิลมีวิดีโอตัวอย่าง · ปลดล็อกแล้วได้ห้องสอนที่ออกแบบคู่กับสกิล
- เล่นได้เรื่อยๆ: หอคอย ∞ สุ่มห้องจากคำตอบก่อน จึงผ่านได้ทุกห้อง

## ยังค้าง

- ยังไม่ได้ทดสอบกับผู้เล่นที่ไม่รู้กติกา (2–3 คน) และยังไม่ได้ตัดสิน PROCEED / PIVOT / KILL
- ชื่ออังกฤษ + ตรวจเครื่องหมายการค้า (กรมทรัพย์สินทางปัญญา / USPTO) ก่อนล็อก
- สกิลใช้ได้ในโหมดหอคอย แต่หอคอยยังไม่มี "ห้องสกิล" ทุก 5 ชั้น
- ยังไม่มีกราฟิก 3 ระดับสำหรับมือถือสเปกต่ำ
